# Rules for AI Agents
1. At the start of a chat use the "tree" command to see the structure
2. Always read all the css files unless they are unrelated but still read /app/styles.css
3. If you see an TODO.md, prompt the user to Either first do the TODO, or Do what prompt they have given, If the prompt is Do TODO, No need for prompting (Always read todos again if asked to do the Todo)
4. Do not mark todos in TODO.md Yourself, use your own LLM-provided
5. Use font-awsome if you can
6. Do not do TODOs marked with --NOTNOW--
7. DO NOT COMMIT YOURSELF (If not asked)
8. NEVER git push even if asked!
9. Do not use gradients unless asked.
10. Never do git reset -hard, even if asked
11. Keep most padding, margins and all things multiples of 4px or 5px
12. Keep it minimal
13. Don't use emojis unless asked
14. Try to use lowercase everytime (not block capitals)
15. Do not generate summary if unprompted
16. Not to delete tauri/target as deleting will recompile everything
