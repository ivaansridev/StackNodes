# Contributing

## Code Conventions

### CSS

- Read `/app/styles.css` before making any style changes.
- Keep padding, margins, and spacing in multiples of 4px or 5px.
- Do not use gradients unless explicitly required.
- Keep the design minimal.

### Fonts / Icons

- Use Font Awesome for icons where possible.

### General

- Keep code minimal. Avoid unnecessary abstractions or comments.
- Do not add emojis to code, commit messages, the webpage, or documentation.
